# Security policy

This is a personal setup, shared as-is. If you find a security problem (for
example a way for the agent to get past the proxy, the read-only mounts or the
managed policy), please report it privately through GitHub:
**Security → Report a vulnerability** on this repository.

Please don't open a public issue for security problems.

What's in scope: the Dockerfiles, scripts, policy files, proxy config and
workflows in this repo. Claude Code itself, Squid and Debian packages are
maintained upstream; report those to their own projects.
